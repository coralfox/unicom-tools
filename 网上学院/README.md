# 联通网上学院主题专栏刷课助手使用说明

## 基本要求

- 本脚本**只在「主题专栏」内页生效**（网址含 `ind_ThemeCourses`）；进入课程播放页会自动切换为「单课程助手」。其它页面不注入面板，看不到属正常。
- 必须允许脚本跨域：油猴弹出「是否允许访问跨域资源」时选「**总是允许**」（或在脚本详情里确认 `@connect app.campus.chinaunicom.cn`）。不允许则拉课程、提交时长都会失败。
- 需要在 `campus.chinaunicom.cn` 上处于**已登录**状态。
- 在专题页看不到面板时，先刷新页面；仍未出现就确认脚本已启用、当前地址栏是专栏内页。

## 使用流程

1. 进入**主题专栏**，选择要刷的专栏（例如「数字化技术能力认证专区」）。
2. 页面左上角出现蓝色面板「**联通网上学院助手**」即脚本正常运行。面板可拖动；点标题栏 **✕** 收起，左侧会出现「刷课」圆钮，点它恢复。
3. 面板打开后状态行先是**红字**「正在准备…」，接着变**蓝字**「正在获取课程列表，请稍等…」，最后变成**绿字**「课程信息已获取，可以开始刷课」。获取期间「开始刷课」显示为「获取课程中…」，「开始刷课」「全部学习」都置灰（禁用），避免列表没就绪时误操作。
4. 列表默认只勾选**未学完**的课程，可按需增减；点「**开始刷课**」，进度跑到 100% 即本页完成。
5. **翻页不用管**。「自动识别」默认勾选，你在网站上点第 2 页，面板的「当前页」会自动变成 2 并重新拉取该页课程，日志提示「网站已翻到第 X 页」。**不要手动改页码**，也无需再点「更新课程」。刷课进行中不跟随翻页，避免打断。
6. 想一次搞定整个专栏，直接点旁边的「**全部学习**」：弹出确认框 → 确认后自动读取专栏总课程数、一次性加载全部课程、勾选未学完的、切到「激进」模式并立即开始。中途想停就**刷新页面**。

## 参数说明

| 参数 | 说明 |
| --- | --- |
| **专栏ID** | 网址 `?` 后面的数字，默认取当前页面。改成其它专栏的 ID 再点「更新课程」，可刷别的专栏。 |
| **当前页** | 勾选「自动识别」时自动读取课程列表分页条里高亮的页码，输入框置灰不可改；取消勾选后可手动填写，但翻页也不会跟随。 |
| **页课程数** | 接口固定每页 8 门，自动模式下固定为 8 并置灰。**一般不用改**；「全部学习」会自动把它设成专栏总课程数。 |
| **专栏总课程数** | 只读，显示该专栏全部课程数量，用来判断分页范围。 |
| **睡眠时间** | 非并发模式下每门课之间的等待秒数，建议不小于 **1 秒**。 |
| **自动识别** | 勾选：读课程列表自己的分页条高亮页码 + 持续跟随网站翻页；读不到页码时才用页面课程名逐页反查接口。取消：完全手动。「全部学习」会自动取消它。 |

**刷课模式**

- **非并发**：逐章串行提交，最稳、最慢。
- **并发**：每批同时提交 5 个章节，一轮结束冷却约 32 秒，失败自动重试。
- **激进**：多批并行，速度最快；请求密集，网络差时失败率略高。

## 按钮功能

- **开始刷课**：只刷列表里**已勾选**的课程，本页刷完即停，进度到 100% 结束。
- **全部学习**：与「开始刷课」并排。点击先弹确认框，确认后整栏加载、自动勾选未学完、切激进模式并开始。
- **更新课程**：按「专栏ID / 当前页 / 页课程数」重新拉取列表。改了专栏ID 必须点它；纯翻页不用点。
- **全选 / 选未学完 / 全不选**：批量勾选；「选未学完」跳过进度 100% 的课程。
- **使用说明**：面板内打开说明窗口（按钮、参数、常见问题都在里面）。
- **－ / ✕**：**－** 切迷你模式（只留进度条）；**✕** 隐藏面板，点左侧「刷课」圆钮恢复。
- **运行日志**：默认收起，开始刷课时自动展开，保留最近 5 条。
- **油猴菜单**：点浏览器工具栏油猴图标，在脚本名下可直接操作「显示/隐藏面板」「完整/迷你切换」「刷课模式（非并发/并发/激进）」「全部学习」「使用说明」，与面板保持同步。
- **刷当前课程**：仅在**课程播放页**出现，提交本课程全部章节的学习时长。

> 旧版的「一键完成周任务课程」已移除，该功能在当前站点不可用。

## 实现原理

- 不模拟页面点击，直接调用站内接口：拉专栏课程列表、拉课程章节（`course/info`）、提交学习时长，因此不需要真的把视频播完。
- 请求里的 **sign** 加密参数：把参数按字段名排序拼成 `k=v&...` 字符串 → 算 MD5 → 用站内同一套 RSA 公钥加密成签名。服务端校验通过即视为有效学习。
- 服务端限制单次提交的学习时长上限为 **179 秒**，单个视频最多走 **5 轮**，累计到视频总时长即为完成。
- 「自动识别」每秒读一次课程列表分页条的高亮页码，变化即重新拉课；用 `.item-title` 锚定「课程列表自己的」分页条，避免页面上多个分页条互相干扰。
- 排错：按 **F12** 打开控制台可看请求与日志；面板日志区也能看到当前进度与失败原因。
- 要**立即停止**，直接刷新页面即可，不会有残留操作。

**声明**：脚本只为节省无效挂机时间。请勿恶意大量刷课，优质课程请认真学习。
