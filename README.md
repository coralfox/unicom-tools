# unicom-tools

在联通工作时积攒的一些东西：针对联通网校/在线考试平台的浏览器脚本（Tampermonkey 用户脚本），以及配套的图文教程、离线安装包。

每个子目录是一个独立小项目，各自带脚本、教程和本地安装资源。

## 目录结构

| 子项目 | 用途 | 脚本版本 |
| --- | --- | --- |
| [网上学院](./网上学院/) | 联通党校/网上学院「主题专栏」自动刷课，支持倍速时长提交 | 开发版 3.7 / 稳定版 2.48 |
| [考试答题助手](./考试答题助手/) | 在线考试页解除防作弊限制 + AI 一键答题 | 5.9 |

## 网上学院

脚本名「联通党校-刷课程，可倍速」，作者 ZouYs / coralfox / CountZero，上游地址 <https://greasyfork.org/scripts/475725>。
适用站点 `campus.chinaunicom.cn` 的「主题专栏」内页与课程播放页。

- 不模拟点击，直接调用站内接口拉课程、提交学习时长，不需要真的把视频播完
- 自动识别网站分页条高亮页码，翻页自动跟随；「全部学习」可一次性刷完整个专栏
- 三种刷课模式：非并发（最稳）/ 并发（一批 5 章节）/ 激进（最快）
- 面板支持完整、迷你、隐藏三种形态，位置记忆，运行日志保留最近 5 条

主要文件：

| 文件 | 说明 |
| --- | --- |
| `联通网上学院-刷课程，可倍速(开发版).txt` | 当前开发版脚本（v3.7），功能较全 |
| `联通网上学院-刷课程，可倍速(稳定版).txt` | 稳定版脚本（v2.48），保守可用 |
| `联通网上学院挂课(插件脚本).html` | 完整图文教程（分发版，可直接发人/离线看） |
| `网上学院自动刷课.rar` | 旧版打包备份 |
| `01.tampermonkey_stable(高版本).crx` / `02.tampermonkey_legacy(低版本).crx` | 离线安装用的 Tampermonkey 扩展 |

使用前必看：脚本只能在专栏内页生效，需要已登录，且油猴弹出跨域授权时要选「总是允许」（`@connect app.campus.chinaunicom.cn`）。

> 注意：脚本内部 `@name` 与发布名是「联通党校-刷课程，可倍速」，但仓库里的文件名是「联通网上学院-刷课程，可倍速(...)」，两者是同一个脚本，别当成两个。

## 考试答题助手

脚本名「联通考试助手 - 防作弊拦截+自动答题」，作者 Coralfox，适用站点 `campus.chinaunicom.cn/training/pc/*`，考试列表页和试卷页都生效。

- 解除防作弊限制：切窗口不再提示离开考试、不强制全屏、不屏蔽右键和复制
- AI 一键答题：内置爱思 Agnes / DeepSeek / 通义千问 / 智谱 GLM / Kimi 等接口预设，答案标注在题目旁，可选自动点选
- 支持上传本地题库/讲义（`.txt .md .csv .json .tsv .log`）作为参考，提高答对率
- 手动粘贴答案批量填写；一键抓取全部题目（自动翻页）

> 脚本本身不带 AI，需要自备 API Key；Key 只存浏览器本地存储。

主要文件：

| 文件 | 说明 |
| --- | --- |
| `联通考试助手.user.js` | 主脚本（v5.9），油猴可直接安装 |
| `联通考试助手.txt` | 同版本脚本的文本副本，便于分发 |
| `联通考试助手使用教程.html` | 图文教程（分发版，含接口申请、答疑附录） |
| `联通考试助手.rar` | 打包备份 |
| `01.tampermonkey_stable(高版本).crx` / `02.tampermonkey_legacy(低版本).crx` | 离线安装用的 Tampermonkey 扩展 |

## 通用安装流程

1. 装 Tampermonkey：能连 Chrome 商店就在线装；否则开浏览器「开发者模式」，把 `.crx` 拖进扩展页。高版本装不上时换低版本（奇安信、老版 360 常见）。
2. 把 `.user.js` 或 `.txt` 脚本文件拖进油猴管理面板，确认安装。
3. 打开对应站点页面，按各项目教程检查面板是否出现、跨域授权是否放行。
